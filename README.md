# Negative Parental Switch

## Overview
This repository contains all supplementary materials and analyses for the paper  
**"Integration of hunger and hormonal state gates infant-directed aggression."**

Each folder named `NPS_*` corresponds to a different subsection of the NPS analysis.  
All subsections are organized so they can be explored and reproduced independently.  

Please note: in some cases, source data files (e.g., large `.csv` files) have been omitted due to size limits.  
If you require access to the full datasets, please contact the corresponding author.
